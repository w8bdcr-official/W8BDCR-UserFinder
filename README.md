## What it does

W8BDCR UserFinder checks a username across social platforms and saves the profiles it finds into a text file named after the username.

## How it works

1. Type a username
2. It checks the username across social platforms
3. Found profiles are saved into a text file

## Quick Start

```bash
apt update
apt upgrade
apt install git
git clone https://github.com/w8bdcr-official/W8BDCR-UserFinder
cd W8BDCR-UserFinder
bash UserFinder.sh
```
